Certification: per test unit (held-out: one deployed decoder version, i.e. one session, with its own slopes and intercepts; replay: one person), output_a = β_body·body_a + β_screen·screen_a + β_cross·body_other + c_a, CR2 cluster-robust SEs with t(G − k) intervals (trials are the clusters); units of one person combined by inverse variance, people by a person-then-trial bootstrap (t with people − 1 df).  βs are relative to the deployed decoder's EXTERNAL margin: its slope on body intent in the identity trials (0.33 of each held-out block, interleaved, never certified), whose SE is propagated into every threshold test; 'margin L1' is the secondary slope on the fixed L1 pool.  Verdict family (Holm, per axis): β_body > 0, β_body > 50 % of the margin (and the point estimate ≥ 70 %), |β_screen| < 10 % (two one-sided tests), and each shadow's β_screen above its NULL — the same shadow, same units, at screen leak 0 (in brackets). Trials whose keyed report (C2b, post-replay) does not confirm the intent are dropped.  Held-out blocks are rot+90 and rot−90 in every session with balanced diagonal targets; replays do not consume a goal quadrant and replay diagonal trajectories inside held-out blocks.  Regressors use the cursor at the window start; C2b and C2c are also reported separately.  Intent is an oracle (exact cued body vector; instant remapping), so β_body is an upper bound.  'Just intend' blocks are not simulated.

Idle gate: rest windows (L0: setup rest and the rest between probes, which now carries the post-imagery beta rebound) against the decoder's training windows; armed only if its out-of-fold AUC ≥ 0.70, and then the output is exactly 0 when p(idle) > 0.7.
