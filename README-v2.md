# Soroush Zare - Personal Website Version 2

## 🧠 Enhanced 3D Brain Interface

This is Version 2 of Soroush Zare's personal website, featuring advanced 3D visualizations and modern interactive elements.

## ✨ New Features in Version 2

### 🎯 3D Brain Visualization
- **Interactive 3D Brain Model**: Built with Three.js
- **Neural Network Connections**: Animated neural pathways
- **Realistic Brain Anatomy**: Separate hemispheres, cerebellum, and brain stem
- **Dynamic Lighting**: Multiple light sources for depth and realism
- **Glow Effects**: Subtle glow around the brain model

### 🎮 Interactive Controls
- **Brain Toggle**: Show/hide the 3D brain
- **Camera Reset**: Return to default viewing angle
- **Particle Toggle**: Enable/disable background particles
- **Orbit Controls**: Click and drag to rotate the brain
- **Auto-rotation**: Smooth automatic rotation

### 🌟 Visual Enhancements
- **Glass Morphism Design**: Modern glass-like cards and elements
- **Particle System**: Floating particles in the background
- **Smooth Animations**: CSS and JavaScript-powered transitions
- **Loading Screen**: Professional loading animation
- **Typing Effect**: Animated text in the header

### 📱 Responsive Design
- **Mobile Optimized**: Works perfectly on all devices
- **Touch Controls**: Touch-friendly interface
- **Performance Optimized**: Smooth 60fps animations

## 🛠️ Technical Stack

### Frontend Technologies
- **HTML5**: Semantic markup
- **CSS3**: Modern styling with CSS Grid and Flexbox
- **JavaScript (ES6+)**: Modern JavaScript with classes
- **Three.js**: 3D graphics library
- **Font Awesome**: Icon library

### Key Libraries
- **Three.js**: 3D graphics and WebGL rendering
- **OrbitControls**: Camera controls for 3D scene
- **Intersection Observer**: Scroll animations

## 🚀 How to Use

### Running the Website
1. Open `index-v2.html` in a modern web browser
2. Wait for the loading screen to complete
3. Interact with the 3D brain using the control buttons
4. Scroll through the sections to see animations

### 3D Brain Controls
- **Brain Icon**: Toggle 3D brain visibility
- **Home Icon**: Reset camera position
- **Star Icon**: Toggle particle effects
- **Mouse/Touch**: Click and drag to rotate brain

## 🔧 Customization

### Modifying the 3D Brain
The brain model can be customized in `script-v2.js`:
- Change colors in `brainMaterial`
- Adjust size and position of brain parts
- Modify neural connection density
- Add more brain regions

### Styling Changes
CSS variables in `index-v2.html` allow easy theming:
```css
:root {
  --accent-blue: #4da3ff;
  --accent-cyan: #00d4ff;
  --bg-dark: #0a0a0a;
}
```
